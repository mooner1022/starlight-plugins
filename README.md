# StarLight Plugins

Plugin repository for [Project StarLight](https://github.com/mooner1022/StarLight). The app's plugin store reads `index.json` from this repository.

> The plugins currently listed here are **sample entries** used to build the store. Their `.slp` files are stub plugins that load but do nothing.

## Layout

```
repository.json            Store metadata: name, categories, featured plugins, verified authors
index.json                 Generated by scripts/build_index.py; the only file the store list fetches
plugins/<plugin id>/
  plugin.json              Store listing written by the plugin author
  README.md                Description shown on the plugin page (Markdown)
  icon.png                 Square icon, 512x512 recommended
  screenshots/*.png        Optional, 9:16 recommended
  releases/*.slp           One file per released version
scripts/build_index.py     Regenerates index.json
```

## plugin.json

```json
{
  "id": "dev.example.plugin",
  "name": "Example",
  "summary": "One line shown in the list",
  "authors": [{ "name": "example", "url": "https://github.com/example" }],
  "category": "utility",
  "tags": ["tag"],
  "license": "MIT",
  "source": "https://github.com/example/plugin",
  "publishedAt": "2026-01-01T00:00:00Z",
  "screenshots": [{ "file": "screenshots/1.png", "caption": "Caption" }],
  "releases": [
    { "file": "releases/plugin-1.0.0.slp", "releasedAt": "2026-01-01T00:00:00Z", "changelog": "- First release" }
  ]
}
```

- `id` must match the directory name and the `id` in the plugin's `assets/starlight.json`.
- `category` must be one of the ids in `repository.json`.
- Version, PluginCore API version, dependencies and native library use come from `assets/starlight.json` inside each `.slp`. File size and SHA-256 are computed by the build script, so they always match the file.

## Adding or updating a plugin

1. Add or update `plugins/<plugin id>/` (a new release is a new `.slp` file plus an entry in `releases`).
2. Run `python scripts/build_index.py`.
3. Commit the changes together with the regenerated `index.json`.

All paths in `index.json` are relative to the repository root.
