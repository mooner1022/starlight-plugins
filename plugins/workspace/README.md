MCP 서버, 웹 IDE 같은 도구 플러그인이 함께 쓰는 라이브러리예요. 이 플러그인만으로는 화면이 없고, 이 플러그인이 필요한 플러그인을 설치하면 함께 설치돼요.

## 하는 일

- 프로젝트 파일 읽기·쓰기·수정·검색 (프로젝트 밖 경로는 막아요)
- 다른 도구가 바꾼 파일을 덮어쓰지 않도록 충돌 감지
- 컴파일과 오류 위치, 이벤트 설정, 프로젝트 만들기
- 프로젝트·앱 로그, 디버그룸 메시지
- 도구끼리 변경 사항 공유: AI가 MCP로 고친 파일이 웹 IDE에 바로 반영돼요

## 플러그인 개발자라면

`starlight.json`에 `"dependency": ["workspace@1.0.0"]`를 넣고, 저장소의 `apiJar` 결과물을 `compileOnly`로 쓰세요.
자세한 내용은 [GitHub](https://github.com/mooner1022/starlight-workspace)를 참고하세요.
