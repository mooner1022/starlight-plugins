카카오톡 데이터베이스를 직접 읽어 메시지·삭제·입퇴장 같은 이벤트를 프로젝트에 전달해요.
알림 기반 수신과 달리 방 알림을 꺼 두었거나 카카오톡을 보고 있어도 메시지를 받아요.

## 사용법

프로젝트 설정에서 쓸 이벤트를 켜면 호출돼요. 이벤트는 연결한 뒤에 새로 저장된 기록에 대해서만 발생해요.

```js
function onKakaoMessage(msg) {
    if (msg.text == "!읽음")
        msg.reply("안 읽은 사람: " + msg.getUnreadCount() + "명");
}

function onKakaoMessageDeleted(event) {
    if (event.message != null)
        event.room.send(event.message.sender.name + "님이 삭제한 메시지: " + event.message.text);
}
```

## 기능

- **메시지**: 정확한 방/유저 ID, 멘션, 답장 원본, 미디어 정보를 함께 받아요.
- **피드 이벤트**: 메시지 삭제, 가리기, 입장, 퇴장, 강퇴, 부방장·방장 변경을 받아요.
- **조회**: 전역 객체 `KakaoDB`로 방 목록, 멤버, 친구, 지난 메시지, 안 읽은 사람 수를 읽어요.
- **호환 이벤트**: 기존 `onMessage`/`onMessageDeleted` 스크립트를 DB 기반으로 돌릴 수 있어요. 플러그인 설정과 프로젝트에서 켜요.
- **보내기**: 카카오톡 알림의 답장 기능으로 보내요. StarLight가 시작된 뒤 그 방의 알림을 한 번이라도 받아야 보낼 수 있고, 알림을 끈 방에는 보낼 수 없어요.

## 필요한 것

- StarLight nightly(PluginCore 1.0.0 이상). StarLight 1.1.0 이상에서는 StarLight AI가 이 플러그인의 API와 가이드를 읽어요.
- 카카오톡 DB를 읽을 방법. 카카오톡의 비공개 폴더에 있어서 보통은 읽을 수 없어요. 처음 설치하면 뜨는 **초기 설정** 창에서 골라요.
  - **루트**: 루팅된 기기(Android 10 이상)에서 `su`로 도우미를 띄워 읽어요.
  - **공유 UID**: 루트 없이 써요. 카카오톡과 도우미 앱을 같은 UID로 패치해 설치하고, 패치와 설치는 초기 설정 창에서 해요. 패치한 카카오톡이 원래 앱을 대체하니 카카오톡 데이터를 먼저 백업하세요. 지원 여부는 Android 버전과 기기 환경에 따라 다를 수 있어요.
  - **직접**: 파일을 이미 읽을 수 있는 환경(SELinux가 꺼진 redroid 등)에서 써요. 최근 카카오톡의 친구 목록은 읽지 못해 친구가 "알 수 없는 사용자"로 보여요.

설정 항목, 이벤트와 스크립트 객체, 각 접근 방식의 자세한 내용은 [소스 저장소](https://github.com/mooner1022/starlight-kakaodb)에 있어요.
