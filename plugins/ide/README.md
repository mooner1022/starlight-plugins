PC 브라우저에서 기기의 봇 프로젝트를 편집하고, 컴파일하고, 디버그룸으로 바로 시험해 볼 수 있어요.
에디터는 VS Code와 같은 Monaco이고, StarLight API 자동완성을 지원해요.

**Ktor**, **Workspace** 플러그인이 함께 설치돼요.

## 시작하기

1. 플러그인 설정 > 보안에서 **접근 토큰**을 정해요.
2. 제어 > 상태를 눌러 주소(`http://<기기 IP>:8766`)를 복사해요.
3. PC 브라우저에서 열고 토큰으로 로그인해요.

## 기능

- 프로젝트·파일 트리, 탭, 파일 찾기(Ctrl+P), 명령 팔레트(F1)
- StarLight API·이벤트 타입 자동완성, `onMessage` 같은 이벤트 함수 틀 넣기
- 컴파일(Ctrl+Shift+B)과 오류 줄 표시, 실시간 로그, 프로젝트 검색
- 디버그룸 채팅으로 봇에게 바로 말 걸기
- 저장할 때 충돌 감지: 앱이나 AI(MCP)가 그사이 바꾼 파일은 비교 화면에서 골라요
- Ctrl+클릭으로 선언부나 참조로 이동 (StarLight API는 타입 선언을 보여 줘요)
- 프로젝트 로그와 앱 전체 로그
- 이벤트를 발신원별로 보고 켜기/끄기, 프로젝트 만들기·정렬·검색
- 설정(Ctrl+,): 테마, 강조 색, 에디터 글꼴·탭 크기·줄 바꿈·미니맵, 디버그룸 보내기 키
- 컴파일되지 않은 프로젝트는 꺼져 있어요. 켜려 하면 "컴파일하고 켜기"를 제안해요
